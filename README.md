# Мишконтин и кралят плъх Мортис — концепция „Heroes“

*Приказна походова стратегия за деца в стила на **Heroes of Might and Magic III**.*
Браузърна игра на български: карта с мъгла, градове, наемане на войска, герои с нива и
магии, тактически битки на шестоъгълно поле — и история с избори, които имат последствия.

> Това е клонът **`heroes-concept`**. Оригиналният 2D платформър (v0.1.1) живее непокътнат
> в клона **`Mishkontin`**. Файловете му (`src/`, `tools/`, `public/`, `release/`, `art/`)
> са оставени тук само за справка — новата игра не ги използва.

## Какво има

- **Кампания от 3 глави, изцяло по книгата** „Мишконтин и краля плъх Мортис“
  (`docs/STORY_BIBLE.md`):
  1. *По следите* — нощта на нападението, празният Сиренград в старата мелница, баба
     Шушулка, мишките от Зелендол, Искрица, здравецът и ранения Летко (Летокрил).
  2. *Тиранинът на гората* — порът Зъбодробко, катериците, полевките и зайците заедно,
     планът със склона и въжената стълба.
  3. *Тъмните тунели* — търпението при Каньона и капаните, стотиците клетки, огнените
     обръчи и лостът, старият Мортис, орлите на Златокрил и „Пусни го.“
- **Избори и добродетели** (Смелост, Честност, Доброта, Мъдрост) — уроците от книгата;
  пренасят се между главите, дават бонуси и променят пътя и края.
- **Карта:** терени с различна цена, пътища, мъгла на войната, ден/седмица/месец, мини,
  ресурси (трохи, клонки, камъчета, сирене), сандъци, артефакти, светилища, пазени
  съкровища (зони на контрол), събития, скрити капани, дни на почивка.
- **Градове:** 15 сгради, седмичен прираст, наемане, пазар, таверна, библиотека с магии.
- **Две фракции + обитатели на гората:** съюзът на малките (полски мишки, полевки,
  катерици, зайци, орли на Златокрил), ордата на Мортис (плъхове от тунелите,
  копиеносци, капанджии, ветерани на Белегор, червенооки гвардейци), порове и диви котки.
- **Герои:** нива, 4 първични умения, 9 вторични умения, артефакти, 9 магии, специалности.
- **Битки:** инициатива, ход/атака, стрелба, ответ, морал, късмет, способности,
  магии, авто-битка, бягство; ИИ на противника.
- **ИИ на картата**, който трупа армия, превзема мини, напада, пази дома си; сценарийни
  вълни и бос.
- **Запис/зареждане** (3 места + автоматичен запис, `localStorage`), главно меню, избор на
  глава, 3 трудности, помощ.
- **Музика и звуци** — създават се в браузъра (Web Audio), без звукови файлове: отделни
  мелодии за менюто, картата, битките и обсадата; звуци за стъпки, удари, магии, строене,
  ново ниво, победа и др. Включват се/изключват от менюто.
- **Мобилни устройства** — докосване (докосни поле, докосни пак = тръгни), плъзгане на
  картата, щипване с два пръста за мащаб, задържане = подробности; подредба за телефон
  вертикално и хоризонтално; бутон „Цял екран“.

Дизайнът е описан в `docs/GAME_DESIGN.md`.

## Как се играе

- **Карта:** щракни поле → вижда се пътят (зелено = днес, оранжево = по-късно); щракни пак
  или натисни `Интервал`, за да тръгнеш. Щракни своя герой/град, за да ги отвориш.
  Десен бутон — подробности. Влачи картата, стрелки/WASD, колелцето = мащаб.
- **Клавиши:** `E` край на хода · `H` следващ герой · `T` град · `Q` задачи ·
  `C` центрирай · `Esc` меню.
- **Град:** по една сграда на ден; наетите отиват при героя в града (ако има място), иначе
  в гарнизона. Щракни отряд и после място, за да местиш; `Shift` разделя наполовина.
- **Битка:** щракни поле (ход) или враг (атака — посоката на мишката избира откъде).
  `W` изчакай · `D` защита · `C` магия · `A` авто. Десен бутон върху отряд — подробности.

## Стартиране

Нужни са Node.js 18+ (тествано с 22) и npm.

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # проверка на типовете + продукционна версия в dist/
npm run preview    # сервира dist/ на http://localhost:4173
```

### Един HTML файл

```bash
npm run build:single   # -> release/mishkontin-heroes.html (~1 MB, всичко е вградено)
```

Файлът се отваря директно с двоен клик — на компютър или телефон, без сървър.

`dist/` е статична и работи с относителни пътища (`base: './'`) — може да се качи на
всеки статичен хостинг или да се отвори през локален сървър.

## Тестове

```bash
npm test           # правила (битка, движение, икономика, история, запис) + баланс
npm run build && npm run e2e   # Playwright: истински браузър срещу продукционната версия
```

- `tests/combat.test.ts` — шестоъгълна геометрия, формула за щети, способности, ответ,
  стрелба, магии, авто-битка.
- `tests/adventure.test.ts` — цена на терена, пътища, зони на контрол, мъгла, точки
  движение, доход, строене, прираст, наемане (отстъпка за Честност), пазар, цялост на
  диалозите, пренос между главите, детерминистичен запис/зареждане, капаните в каньона и
  дните на почивка.
- `tests/balance.test.ts` — тестов бот изиграва главите на фиксирани сийдове.
- `e2e/playthrough.spec.ts` — меню → нова кампания → диалог → Сиренград (строене и
  наемане) → битка с патрула → здравецът → честният отговор към мишките от Зелендол
  (Искрица се присъединява) → запис → презареждане → зареждане; и цяла глава 1, изиграна
  от бота, с преминаване към глава 2.

Playwright използва предварително инсталиран Chromium (`PLAYWRIGHT_BROWSERS_PATH`), ако има
такъв; иначе `npx playwright install chromium`.

## Структура

```
index.html              страница (#app)
vite.config.ts          Vite (publicDir: public-heroes, base: ./)
game/
  main.ts               старт + малка кука за тестовете (window.__game)
  core/                 правилата, без DOM (тестват се в Node)
    types.ts            състоянието на играта (един JSON обект — така се записва)
    rng.ts              детерминистичен генератор на случайни числа
    map.ts              терен, пътища (Dijkstra), зони на контрол, мъгла
    hero.ts             производни стойности, армии, опит и нива, добродетели
    combat.ts           битката: шестоъгълници, ред, щети, способности, магии, ИИ
    town.ts             сгради, прираст, наемане, пазар, таверна, местене на войска
    adventure.ts        нова игра, дни, движение, обекти, битки на картата, история
    ai.ts               ИИ на картата (и тестовият бот)
    bot.ts              бот, който отговаря на диалози и играе за тестовете
    scenario.ts         типове за сценарии, тригери, действия, диалози
  data/                 съдържанието: същества, магии, артефакти, сгради, герои,
    scenarios/          персонажи и трите глави (карта в ASCII + легенда + диалози)
  ui/                   интерфейсът: DOM панели + Canvas за картата и битката
public-heroes/          картинки за играта (портрети на Мишконтин, 4 фона от рисунките на проекта)
docs/                   библия на историята и дизайн документ
tests/, e2e/            автоматични тестове
```

Сценариите са данни: картата е масив от низове (всеки символ е терен или ключ от
легендата), а историята — тригери и диалози с избори. Нова глава = нов файл в
`game/data/scenarios/`.
